# Skillio State Testing

Open `src/data/homeData.js`.

## Scheduled class
Set:
`scheduledClass` to the sample object.

## No class
Set:
`scheduledClass: null`

## Practice incomplete
Set:
`dailyPractice.completedToday: false`

## Practice complete
Set:
`dailyPractice.completedToday: true`

## No active subscription
Set:
`subscription.active: false`

## No lessons
Set:
`subscription.lessonsRemaining: 0`

The demo also has buttons on the home screen to toggle class and practice state.
